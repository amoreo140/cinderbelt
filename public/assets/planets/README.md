# Cinderbelt – planet textures (M5 / M5b)

Generated by `art/blender/planets.py` (Cycles panoramic camera inside a
procedural sphere → exact equirectangular, seamless in longitude, poles at the
top/bottom) and `art/blender/gas_giant.py` (ring system). Every parameter the
game needs is in `planets.json` (its `_schema` key documents each field).

**4 types × 3 biomes** (spec 5.6 "4 types × 3 biomes = 12, plus gas giants") + the hero gas giant:

| type | biomes (`<type>_<biome>`) | deposits (main) | base mode |
|---|---|---|---|
| rocky | `rocky_arid`, `rocky_temperate`, `rocky_barren` | iron, copper, titanium, rareEarth, ice | ground |
| ice | `ice_glacier`, `ice_frozen_sea`, `ice_cryo` | ice, titanium, helium3, crystal | ground |
| gas | `gas_amber`, `gas_azure`, `gas_violet` | helium3, ice, crystal | float |
| volcanic | `volcanic_fissure`, `volcanic_lava_sea`, `volcanic_sulfur` | rareEarth, iron, copper, titanium | ground |
| special | `gas_giant` (+ ring system) | helium3 | float |

| File | Size | Colour space | Use |
|---|---|---|---|
| `<name>_albedo.webp` | 2048×1024 (`gas_giant` 4096×2048) | sRGB | `map` on a sphere with equirect UVs (three.js `SphereGeometry` default UVs). No atmosphere baked in. |
| `<name>_normal.webp` | 1024×512 | linear (`NoColorSpace`) | `normalMap`, tangent space, OpenGL (+Y = north = up in the image). Not for gas. `normalScale` from the JSON. |
| `<name>_emissive.webp` | 2048×1024 | sRGB | volcanic lava + `ice_cryo` vents: `emissiveMap`, `emissive = #ffffff`, `emissiveIntensity` from the JSON. |
| `clouds_1..3.webp` | 2048×1024 RGBA | sRGB | 1 wispy streaks, 2 cumulus fields, 3 banded swirls; white RGB, alpha = density |
| `gas_giant_ring.png` | 2048×64 RGBA | sRGB | radial ring profile (u = inner→outer edge), alpha = opacity |
| `../models/planets/gas_giant_rings.glb` | – | – | ring annulus, radii 1.28–2.35 **in planet radii**, equatorial plane (glTF XZ), own alpha-blended double-sided material |

Rendering suggestion: planet sphere (albedo + normal [+ emissive]), a cloud
sphere at `clouds.shellScale` (alpha blending, depthWrite false, longitude
scroll `clouds.speed`), and an atmosphere shell at `atmosphere.shellScale` with
an additive fresnel rim (`atmosphere.color`, `density`, exponent `power`),
brighter on the lit side. Spin the planet about its own axis first, then tilt;
give the ring the same tilt. Bases sit on the surface UNDER the cloud shell –
fade the clouds around a base. Keep a base away from the texture poles (equirect
pinch).

Renamed in M5b (`legacy` key): rocky_a → rocky_arid, rocky_b → rocky_temperate,
ice_a → ice_glacier, ice_b → ice_frozen_sea, gas_a → gas_amber, gas_b → gas_azure,
volcanic_a → volcanic_fissure, volcanic_b → volcanic_lava_sea.
`planets.py` renders JPG/PNG; its optimizer post-step (`npm run assets:optimize`, `art/README.md`
§2.9) converts them to WebP (albedo lossy q92, normal/emissive lossless, clouds with lossless
alpha) and rewrites the names in `planets.json`.
