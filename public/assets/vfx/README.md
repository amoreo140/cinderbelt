# Cinderbelt – VFX textures

Generated by `art/blender/vfx.py` (sprites) and `art/blender/vfx_explosion.py`
(Cycles volume flipbooks). Re-run:
`blender --background --factory-startup --python art/blender/vfx.py`.

All files are **RGBA PNG, straight (non-premultiplied) alpha, sRGB colour**
→ in three.js use `texture.colorSpace = THREE.SRGBColorSpace`
(except `flame_noise.png`, which is data: `THREE.NoColorSpace`).
Row 0 is the top of the image; with the default `flipY = true` the top of the
image is `v = 1`. "White" textures are meant to be tinted by
`material.color` / vertex colour.

### Sector borders (`art/blender/vfx_borders.py`, art batch C4)

All white (tint with the security colour = UI token, `models/borders/borders.json`), straight alpha, `RepeatWrapping` on u (u = along the border), v = across the strip with the core at v 0.5 and alpha 0 at both long edges. Additive (colour × alpha) is the intended blending; normal blending also works.

| File | Size / layout | Colour | Blending | Notes |
|---|---|---|---|---|
| `border_ribbon.png` | 256×64, tileable on u | white | additive | soft volumetric haze band with slow wisps, no hard edges. Flat ribbon in the plane (or a low curtain) along the sector boundary spline, width ~14 u, u repeat every ~40 u, opacity 0.25–0.35, scroll u ~0.02/s |
| `border_fence_guarded.png` | 128×32, tileable on u | white (tint `--af-ok`) | additive | two evenly spaced solid dashes per tile (= solid fill on the map) |
| `border_fence_quiet.png` | 128×32, tileable on u | white (tint map grey-blue) | additive | two sparse soft dots per tile |
| `border_fence_contested.png` | 128×32, tileable on u | white (tint `--af-warn`) | additive | irregular broken dashes (= dotted fill); scroll u for a flicker |
| `border_fence_pirate.png` | 128×32, tileable on u | white (tint `--af-bad`) | additive | zigzag barbed-wire line with crossed barbs (= hatching) |

Fences: a camera-facing strip ~0.7 u wide from marker *i* `fence_l` to marker *i+1* `fence_r`, following the boundary spline, u repeat every ~6 u. The shapes differ per security level so the border also reads in greyscale / for colour-blind players. Preview `art/out/previews/batch-c-vfx.png`, in context `batch-c-borders-gamecam.png`.

Flipbook UVs (N×N grid, frame `i`, row-major from the top-left, flipY = true):
`u = (col + uv.x) / N`, `v = 1 - (row + 1 - uv.y) / N` with `col = i % N`, `row = floor(i / N)`.

The flipbooks are generated as PNG and shipped as WebP (q95, lossless alpha) by the optimizer
post-step (`npm run assets:optimize`, `art/README.md` §2.9); `vfx.py --only explosions` runs it.

Previews: `art/out/previews/vfx-sheet.png`, `vfx-explosion-frames.png`, `vfx-explosion.mp4`.
